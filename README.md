# Game HTTP Server

Серверная часть небольшой игровой симуляции на C++. Сервер принимает HTTP-запросы, хранит состояние игрового мира, обновляет его со временем и возвращает клиенту данные в JSON. В проекте также есть работа со столкновениями, игровыми предметами и сохранением состояния.

**Технологии:** C++20, Boost.Asio / Boost.Beast / Boost.JSON (Boost 1.78), PostgreSQL, libpqxx.
